    - 市場規模推計は調査会社によってブレが大きいため、1つの数字を絶対視せず、**カテゴリとして予算が立つか** を重視する
    - 規制・実務運用は地域差が大きいため、PoC時には対象国・対象業界・対象商品をさらに限定すること
